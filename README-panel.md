# Alisa Panel

Компактная веб-панель на станции: Quasar Bridge и ChatGPT Voice в одном месте,
со встроенной справкой. Работает без ПК и без интернета, только в локальной сети.

> Проверено на Яндекс Станции 2 (`yandexmidi`); другие модели не тестировались.

```
Alisa Panel        SPEAKER_IP · Станция 2 · 0.369.1.46
[ Bridge: работает ] [ GPT: idle ] [ VPN: выкл ]
[ Открыть чат ] [ Новый чат ] [ Вернуться к Алисе ]
```

## Что нужно

- Станция с уже полученными root и SSH — [инструкции hackalice.me](https://hackalice.me/start/).
- Entware на станции. `lighttpd` с CGI/Basic auth установщик поставит сам
  (`opkg install lighttpd lighttpd-mod-cgi lighttpd-mod-auth lighttpd-mod-authn_file lighttpd-mod-access`).
  В прошивке этой Станции BusyBox `httpd` отсутствует.
- Свободный порт `8099` (меняется флагом `--http-port`).

## Установка с Mac

Из папки проекта:

```sh
./install-panel.sh
```

Без флагов берёт `host`, `port` и ключ из установленного CLI
(`~/.local/state/alisa-voice/native/config.json`). Явно:

```sh
./install-panel.sh --host SPEAKER_IP --ssh-port 2222
```

Скрипт копирует панель в `/data/opt/alisa-panel`, при необходимости ставит
`lighttpd` из Entware, проверяет его на временном порту (401/200/CGI), создаёт
init-скрипт `S99zz-alisa-panel`, запускает панель и печатает адрес, логин и пароль.
Пароль генерируется на станции; на Mac он не передаётся. При первом запуске нужен
доступ станции к Entware.

Флаги: `--http-port 8099`, `--identity FILE`, `--uninstall`, `--keep`, `--no-verify`.

## Доступ

Откройте `http://<IP-станции>:8099/`, логин `admin`. Пароль хранится на станции:

```
/data/opt/alisa-panel/panel.conf   (0600)
```

Сменить пароль можно во вкладке «Обслуживание». После смены панель перезапустится
через 2 секунды, браузер попросит пароль заново.

## Что внутри

- **Обзор**: статусы Bridge/GPT/VPN, открыть/новый/предыдущий чат, вернуть Алису,
  запуск/остановка/перезапуск.
- **ChatGPT**: разговоры, голос, подсветка (стиль, паузы, режим), фразы после
  «Алиса», автозапуск, STUN, VLESS (старт/стоп), журнал. В блоках «Голос и подсветка»
  и «Автозапуск и сеть» одна общая кнопка «Сохранить»; STUN при изменении
  перезапускает GPT с подтверждением.
- **Quasar Bridge**: процесс, health, endpoint, старт/стоп/перезапуск, проверки,
  подключение LLM/HA (`runtime.env`), редактор `config.json`, apply/rollback endpoint.
  Журнал показывает время, уровень и понятное событие; фильтры «Важное / Все /
  только ошибки», автообновление и сырой JSON по клику. «Важное» скрывает
  служебные кадры и повторяющиеся статусы.
  Модель выбирается из подсказок: кнопка ↻ загружает список `/models` (нужен
  рабочий ключ), иначе подставляются типовые модели; ввод вручную сохраняется.
- **Справка**: команды, маршрутизация, «Алиса молчит», «ChatGPT не отвечает»,
  возврат Алисы, безопасность.
- **Обслуживание**: смена пароля, перезагрузка станции, сырой статус.

## Важные особенности

- **Bridge и GPT работают вместе.** Bridge — голосовой сервер Алисы; GPT
  перехватывает разговор. Если Bridge остановлен, Алиса не отвечает.
- **Endpoint.** Пока `endpoint-backup.json` отсутствует, Bridge установлен, но
  прошивка ходит в Яндекс напрямую. Статус показывает «не применён».
- **Ключ LLM** хранится в `runtime.env` и имеет приоритет над `config.json`;
  панель редактирует его отдельными полями.
- **VLESS**: панель запускает уже настроенный туннель и переписывает `runtime.env`
  для GPT (proxy + `mark.so`). Новый сервер настраивается с Mac.
- **Переустановка с Mac** применяет профиль CLI и может вернуть фразы, подсветку,
  STUN и автозапуск к значениям Mac. После обновления проверьте вкладку ChatGPT.
- **Автозапуск** — только флаг; init-скрипт и `boot.sh` ставит Mac-установщик.

## Безопасность

- Только приватные сети (`127.0.0.1`, `192.168/16`, `10/8`, `172.16/12`), остальным
  `D:*`.
- Basic-авторизация + CSRF-токен на все POST; действия — из белого списка.
- HTTP без TLS. Пароль и ключи LLM видны в локальной сети. Не пробрасывайте
  `8099` в интернет и не открывайте из гостевой сети.
- `lighttpd` работает от root, потому что управляет станционными скриптами.
- `lighttpd` из Entware остаётся после удаления панели: он может быть нужен другим
  приложениям. Удалять его вручную через `opkg remove` стоит только если он больше
  нигде не используется.
- Установщик отключает стандартный `/opt/etc/init.d/S80lighttpd`, чтобы после
  перезагрузки не открывался лишний порт. Вернуть его можно `chmod +x`, если нужен
  стандартный сайт Entware.

## Обновление и удаление

```sh
./install-panel.sh                 # обновить, пароль сохранится
./install-panel.sh --uninstall     # остановить и удалить
./install-panel.sh --uninstall --keep   # оставить файлы и журналы
```

Панель не трогает GPT, Bridge, SSH и вход ChatGPT. Их удаление — отдельно
(`alisa native uninstall`, `control.sh rollback`).

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `Остановлено: ... lighttpd` | Не удалось поставить/запустить lighttpd; панель не установлена, прежняя версия не тронута. Проверьте `opkg update` и место в `/opt`. |
| 401 в браузере | Неверный пароль; смотрите `panel.conf` на станции. |
| 403 с Mac | IP не попал в allowlist; проверьте `lighttpd.conf` и `lighttpd.user`. |
| Порт занят | `--http-port 8100`. |
| Панель не поднялась после перезагрузки | Проверьте `/etc/init.d/S99zz-alisa-panel`, `/opt` и `lighttpd.log`. |
| Настройки вернулись после обновления | Так и задумано: Mac CLI — источник профиля; проверьте вкладку ChatGPT. |
