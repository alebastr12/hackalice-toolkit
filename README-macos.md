# ChatGPT Voice на macOS

Установщик нативного режима [Alisa Voice](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant)
для macOS. Ставит клиент ChatGPT Voice на рутованную Яндекс Станцию по SSH; компьютер
после установки и входа не нужен.

Проверено на Станции 2 (`yandexmidi`), прошивка `0.369.1.46.4793639783.20261020.295`:
`doctor` и `install --dry-run` с macOS 27 / Python 3.14 / Chrome. Вход в ChatGPT и
голосовой диалог выполняет владелец колонки.

## Что нужно

- macOS, Python 3.10+ (`brew install python`, если системный старее), `curl`, `patch`.
- Google Chrome, Microsoft Edge или Chromium для однократного входа в ChatGPT.
- Станция с root и SSH. Для Станции 2 обычно порт `2222`.

## Установка

Из папки проекта:

```sh
./bootstrap-macos.sh
```

Скрипт скачивает закреплённый релиз `v0.3.11`, сверяет SHA-256, проверяет состав
пакета, применяет `patches/macos-0.3.11.patch`, пересчитывает manifest и запускает
штатный установщик. Права администратора не нужны.

Полезные флаги:

```sh
./bootstrap-macos.sh --no-run                  # без запуска меню
./bootstrap-macos.sh --archive ~/alisa-voice-linux.tar.gz   # из локального файла + .sha256
./bootstrap-macos.sh --no-link                 # не делать симлинк в Homebrew bin
./bootstrap-macos.sh --version v0.3.11         # явная версия (нужен свой патч)
```

`--force` отключает только сверку версии архива с `--version`. Патч и проверка
manifest выполняются всегда; при несовпадении установка останавливается до записи
в `~/.local`.

Устанавливается:

| Что | Куда |
|---|---|
| Программа и ассеты | `~/.local/share/alisa-voice` |
| Настройки, вход, чаты | `~/.local/state/alisa-voice` |
| Launcher | `~/.local/bin/alisa` (симлинк в `$(brew --prefix)/bin`, если можно) |

Launcher сам перебирает интерпретаторы и требует Python 3.10+, поэтому обновление
Homebrew не ломает команду `alisa`.

## Первый запуск

1. Режим: **нативный**.
2. IP `SPEAKER_IP`, порт `2222`, пользователь `root`. Пароль нужен только чтобы
   поставить отдельный SSH-ключ; пустой ввод — использовать существующий ключ.
   Пароль не сохраняется.
3. VLESS — по желанию, только для трафика GPT.
4. Вход в ChatGPT откроется в отдельном окне Chrome. После входа окно закроется,
   сессия проверится на колонке.
5. Согласитесь на короткий голосовой тест: «Алиса, открой чат».

Управление: `alisa` или `~/.local/bin/alisa`.

## Quasar Bridge

ChatGPT Voice не меняет `quasar.cfg` и не останавливает Quasar Bridge: он поднимает
свой launch-профиль. Мастер покажет предупреждение, если найдёт Bridge на колонке.
Оба режима могут быть установлены, но микрофоном владеет один; если GPT не отвечает,
остановите мост на время проверки. Алиса и умный дом вне чата продолжают работать.

## Обновление

In-place обновление на macOS отключено: upstream-пакет заменил бы пропатченные файлы.
Перезапустите `bootstrap-macos.sh` — состояние, вход и чаты сохранятся. Если вышла
новая версия upstream, нужен свежий патч: `scripts/build-macos-patch.sh` после
обновления `repo/`. Пока патч не обновлён, установщик остановится с понятной ошибкой.

## Откат

Вернуть штатную Алису и удалить программу:

```sh
~/.local/bin/alisa native uninstall
```

Или в меню: «Установка и обслуживание → Удалить программу». SSH, вход ChatGPT и чаты
сохраняются. Быстро остановить GPT без удаления:

```sh
~/.local/bin/alisa native stop
~/.local/bin/alisa native autostart off
```

## Веб-панель

Рядом с CLI можно поставить станционную панель для Bridge и GPT:

```sh
./install-panel.sh
```

Она откроется по `http://<станция>:8099/`; подробности, безопасность и удаление —
в [README-panel.md](README-panel.md).

## Ограничения

- Только нативный режим. Браузерный мост остаётся Linux-only.
- Станция 2: поддержка подсветки панели есть с 0.3.4; отдельного аппаратного прогона
  этой сборки на Станции 2 у сопровождающего нет.
- Патч привязан к 0.3.11 и меняет только host-часть (macOS), станционные файлы — из
  upstream-релиза.
- macOS-часть не отправлена в upstream; патч и установщик публикуются в этом репозитории, обновления — вручную.

## Проверки

```sh
python3 -m unittest discover -s macos/tests -v
ALISA_TEST_ARCHIVE=/path/to/alisa-voice-linux.tar.gz ./macos/tests/test_bootstrap.sh
```

`test_bootstrap.sh` проверяет установку в временный `HOME`, наличие пропатченного
модуля и отказ при неверном SHA-256. Живая проверка:

```sh
~/.local/bin/alisa native doctor --host SPEAKER_IP --port 2222
~/.local/bin/alisa native install --dry-run --host SPEAKER_IP --port 2222
```
